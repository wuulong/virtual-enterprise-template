## 1. 六大職能與主管 Agent 聲明
- `01_HR`: HR Recruiter Agent (`AGT-HR-001`)
- `02_RD`: R&D Architect Agent (`AGT-RD-001`)
- `03_FIN`: Fin Auditor Agent (`AGT-FIN-001`)
- `04_PROC`: Procurement Agent (`AGT-PROC-001`)
- `05_OPS`: Ops Dispatcher Agent (`AGT-OPS-001`)
- `06_MKT`: Sales Copilot Agent (`AGT-MKT-001`)

## 2. RACI 審核邊界
無 A (Accountable) 權限之 Agent 嚴禁觸發金流、開藥或資料庫寫入 API。
