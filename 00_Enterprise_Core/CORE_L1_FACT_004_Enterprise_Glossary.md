# 📚 企業全域專業術語庫 (Enterprise Glossary)

本字典用於統一全域 Agent 與跨部門 Workflow 執行時之語意對齊，防止跨部門語意歧義與 LLM 理解偏差。

---

## 核心術語清單

| 術語名稱 | 英文原名 | 全域定義與說明 | 跨部門語意對齊 |
| :--- | :--- | :--- | :--- |
| **雙軌融合** | Hydration | 將高能耗網頁檢索外包後，將數據注入 APQC/ISO 剛性骨架之過程。 | 全部門通用方法學 |
| **單一真實來源** | SSOT (Single Source of Truth) | 以 GitOps 本地 Markdown/JSON 檔案作為系統唯一權威數據來源。 | 系統架構與知識庫通用 |
| **中控控制面** | Control Plane DB | 連結白皮書 SOP 條號與實體系統 API/SQL 驅動指令之中控資料庫。 | R&D 與 Fin Auditor 對接標的 |
| **影子模式** | Shadow Mode | 將真實事件去識別化抄送至虛擬 Agent 網絡運作進行 Gap Analysis 之測試模式。 | Operations 與 Audit 通用 |
