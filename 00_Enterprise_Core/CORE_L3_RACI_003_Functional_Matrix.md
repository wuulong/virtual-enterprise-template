# 📋 職能列表與 RACI 權責矩陣 (Functional & RACI Matrix)

## RACI 定義說明
- **R (Responsible):** 負責執行任務之 Agent 或角色。
- **A (Accountable):** 最終負責與簽核之 Agent 或主管。
- **C (Consulted):** 需諮詢意見之專業 Agent。
- **I (Informed):** 被通知成果之 Agent。
